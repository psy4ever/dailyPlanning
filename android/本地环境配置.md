## 使用方式

配置完成后，重新启动 Android Studio、VS Code 和终端，使其读取更新后的用户环境变量。用 Android Studio 打开本目录，执行 Gradle Sync，再选择 `app` 和设备运行。

新开的 PowerShell 中可以执行：

```powershell
Set-Location C:\code\dailyPlanning\android
java -version
javac -version
adb version
.\gradlew.bat --version
.\gradlew.bat :app:assembleDebug :app:lintDebug --console=plain
```

`gradlew.bat --version` 的 Launcher JVM 和 Daemon JVM 应使用 JDK 17。APK 输出位置为 `app/build/outputs/apk/debug/app-debug.apk`。首次构建需要联网获取依赖，App 安装后可离线运行。
