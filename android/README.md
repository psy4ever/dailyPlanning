# 日有度 Android 本地版

单一 `:app` 模块，Kotlin + Jetpack Compose + Room。当前三页为“今天、记录、我的”；洞察暂不展示。数据起始为空，没有演示种子或自动生成的生活事实。计划、记账、饮食已接入可选云同步，需先部署配套后端。

当前 0.3.2 已构建公网 IP HTTPS 直连 APK，地址保存在本机 `cloud-api.properties`；云端已启用并通过电脑公网检查，用户反馈手机简单测试未发现明显问题。详细手机流量同步与异常场景仍需继续验收。操作见[手机直连启用步骤](../手机直连-启用步骤.md)。未配置地址的开发构建仍保留本地转发模式；这不适用于当前已配置直连地址的安装包。

新克隆项目后，可在根目录运行 `powershell -ExecutionPolicy Bypass -File .\生成APK.ps1 -CloudApiBaseUrl https://43.142.121.249`，生成连接当前云端的 APK；本机 `cloud-api.properties` 不随仓库分发。

## 打开与运行

用 Android Studio 打开本目录，安装 Android SDK 36，选择 JDK 17 和模拟器或 Android 真机运行 `app`。命令行在本目录运行 `./gradlew :app:assembleDebug`，Windows 为 `.\gradlew.bat :app:assembleDebug`。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

Windows 本机环境配置见[本地环境配置记录](本地环境配置.md)。SDK、JDK 的绝对路径保存在被 Git 忽略的本地配置中，不会随克隆自动安装。Android Studio 的 Gradle JDK 选择 `GRADLE_LOCAL_JAVA_HOME`，并确认其解析到已安装的 JDK 17；首次配置或修改环境变量后，重新启动 Android Studio、VS Code 和终端。

数据先保存在应用私有 Room 数据库 `daily-rhythm.db`。卸载应用会删除本地数据；卸载前请在“我的”导出备份 JSON。未绑定云账户时，文件恢复会替换当前全部本地记录并要求确认；绑定后避免整库覆盖，应在独立安装恢复。备份为明文，需妥善保存。当前备份格式版本为 11，也接受版本 8/9/10 的备份；不导出令牌或同步队列。

本地数据库已在模拟器完成建库、结构与完整性检查，并通过独立数据库的持久化和事务回滚测试。数据库位置、Android Studio 查看方式和复查命令见[本地数据库说明](本地数据库.md)。

参数化 SQL 写入与 Room 读取互通已经过设备端测试；当前可存储模块、118 个表字段和保存规则见[SQL 存储与模块字段](../deliverables/12-本地SQL存储与模块字段.md)。

## 已接入

- 今天：页顶选日；新建/调整时只选当天起止时分下拉框；节点时间线、点击计划详情、完成打卡、取消与可撤销的移除。支持 v1 日计划 JSON 导出、预览导入、前一天复用与按日期范围/星期批量复用。活动可开始、暂停、继续、结束、补记、纠错、删除撤销。
- 记录：首页直接显示热量环、营养素和收支汇总卡片，点击进入详情，首页与详情共享日期；支持分类记账、备注、饮食搜索、食用克数编辑及当日营养目标。睡眠按醒来日归属，记账按入账日归属。食物营养表和多食物摄入保留原营养快照。当前页面以[记录卡片映射](../deliverables/23-记录卡片原型实现与数据库迁移.md)为准。
- 我的：顶部用户卡和设置列表；账户与同步在账户入口，备份导出/恢复在“数据迁移”入口。注册填写昵称/密码，UID 由服务器从 `00000001` 起自动分配；登录优先使用昵称/密码。昵称可重复，同名且密码也相同的账户需用 UID 区分。旧账户过渡期可用原登录名登录。
- 今天：导入本应用导出的日计划 JSON，或包含“在职日时间安排/自由日时间安排”的 TXT 模板；TXT 会先选择一套时间表，跨日睡眠不导入当天计划。普通 TXT 不能用于整库恢复。
- 计划编辑器：可设置近似本地提醒、提前分钟数和静音；通知支持延后 10 分钟。Android 13 及以后需要通知权限，拒绝权限不影响记录。系统可能延迟提醒。

## 已知边界

- 尚未实现多段计时的整体时间纠错、重叠活动的交互式拆分以及真正的重复系列规则。批量复用按日期生成独立计划，默认跳过已有计划日；未提供智能冲突重排。
- 账本与活动现金字段独立，当前没有币种选择，也不自动汇总或互相抵扣。跨日活动按结束日归属；旧活动现金数据仍保留。
- 配套 Spring/MySQL 同步代码见[实际实现映射](../deliverables/17-三模块云同步实现映射与验收.md)，部署和手机连接见[操作步骤](../deliverables/18-云端部署与手机联调操作.md)。云端 API 已健康启动，手机联合验收与 HTTPS 待完成；饮水等 P1/P2 可选模块仍未实现。
- 已在本机 Android 模拟器检查三页布局及记录卡片 / 详情流程；已验证 v10→v11 非破坏迁移、旧备份恢复、新备份往返和三模块 HTTP 同步。通知和长时间计时仍需专项验证，连续两周真机试用仍是自用验收门槛。

`minSdk` 26、`targetSdk` 36；已申请网络权限，系统云备份继续关闭。Room 业务 v1→v11 迁移不使用破坏性重建，独立辅助表保存同步状态。0.3.0 使用同步契约 v2，需配套升级服务器。Release 只接受 HTTPS，Debug 额外允许本机回环地址供 SSH 隧道联调。
