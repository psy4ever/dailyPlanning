## 已确认的关键要求

- Android 手机优先；后端按 Java + Spring，服务端数据库 MySQL。
- 回报维度名称和权重由用户自定义，启用回报分析前必须填写并确认。
- 支持社交/娱乐/收入 3:3:3，或收入/社交/娱乐 4:2:2；权重不必凑成固定总和。
- 权重和各活动实际评分分开；金额、时间、精力作为付出/事实单列。
- 目前不依赖公网或真实模型 API；确切联网条件尚未确认，因此方案同时解释本地与局域网。
- 三餐和任意多次加餐纳入已知摄入热量；食物营养表由用户手工维护，每次填写实际食用克数。饮水、周期、自定义记录是可选后续模块。
- `宪法.txt` 中与项目相符的映射、字段不猜测、按需请求和反向核验原则已写入方案；Vue 专属实现条款未直接套用到 Android。

## 预览边界

对话中提供四页交互预览，可切换导航、演示开始结束、在本次浏览中添加自定义食物与加餐、修改权重并重算。它不是 Android APK，不运行真实计时、不接数据库、不保存真实生活数据。预览中展示的食物、热量、评分和收入均为示例。

可编辑的原型源已整理至 `prototype/index.html`，无需公网依赖。文档中的性能指标、工期、留存门槛都属于待验证目标。
