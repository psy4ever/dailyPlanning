# 日有度 Android 本地版

单一 `:app` 模块，Kotlin + Jetpack Compose + Room。当前三页为“今天、记录、我的”；洞察暂不展示。数据起始为空，没有演示种子、网络权限或自动生成的生活事实。

## 打开与运行

用 Android Studio 打开本目录，安装 Android SDK 36，选择 JDK 17 和模拟器或 Android 真机运行 `app`。命令行在本目录运行 `./gradlew :app:assembleDebug`，Windows 为 `.\gradlew.bat :app:assembleDebug`。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

本机已配置 SDK 于 `C:/Users/psy13/AppData/Local/Android/Sdk`、Eclipse Temurin JDK 17.0.20.1 于 `C:/Users/psy13/.jdks/temurin-17.0.20.1+1`。Android Studio 的 Gradle JDK 本地设置指向 `GRADLE_LOCAL_JAVA_HOME`；若 IDE 打开后显示其他 JDK，请在 Gradle 设置中重新选择该项。重新打开终端可使更新后的用户环境变量生效。

数据保存在应用私有 Room 数据库 `daily-rhythm.db`。卸载应用会删除本地数据；卸载前请在“我的”导出备份 JSON。恢复会替换当前全部本地记录，界面会要求确认。备份为明文，需自行妥善保存。当前备份格式版本为 10，也接受版本 8/9 的备份。

## 已接入

- 今天：页顶选日；新建/调整时只选当天起止时分下拉框；节点时间线、点击计划详情、完成打卡、取消与可撤销的移除。支持 v1 日计划 JSON 导出、预览导入、前一天复用与按日期范围/星期批量复用。活动可开始、暂停、继续、结束、补记、纠错、删除撤销。
- 记录：页顶统一选日；饮食与睡眠弹窗只选时刻。睡眠按醒来日记录；食物营养表和多食物摄入保留原营养快照。记账本可记录收入/支出、来源、金额并编辑或删除。
- 我的：稳定本机档案与可选昵称；明文 JSON 备份与恢复，功能含义直接写在页面。
- 计划编辑器：可设置近似本地提醒、提前分钟数和静音；通知支持延后 10 分钟。Android 13 及以后需要通知权限，拒绝权限不影响记录。系统可能延迟提醒。

## 已知边界

- 尚未实现多段计时的整体时间纠错、重叠活动的交互式拆分以及真正的重复系列规则。批量复用按日期生成独立计划，默认跳过已有计划日；未提供智能冲突重排。
- 账本与活动现金字段独立，当前没有币种选择，也不自动汇总或互相抵扣。跨日活动按结束日归属；旧活动现金数据仍保留。
- 不提供 Spring/MySQL 服务、HTTP 同步、饮水和其他 P1/P2 可选模块。规划契约见 `../deliverables/05-接口字段设计.md`。
- 已在本机 Android 模拟器检查三页布局、单日时刻下拉框、记账弹窗及 v9→v10 数据库升级。批量写入、备份实际恢复、通知和长时间计时仍需专项验证。连续两周真机试用仍是自用验收门槛。

`minSdk` 26、`targetSdk` 36；未申请网络权限，系统云备份已关闭。Room v1→v10 迁移不使用破坏性重建。本轮映射见 `../deliverables/10-日期归属批量计划记账与用户映射.md`。
