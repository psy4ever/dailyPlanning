# 日有度（Daily Rhythm）

Android 优先的私人计划、行为时间、作息与饮食记录应用方案。目标是让计划、执行打卡与回顾形成闭环；个人回报由用户自定义维度和权重，不等同于工资收入。

当前 Android 版为“今天 / 记录 / 我的”三页；洞察与回报权重入口暂停。单日计划只选时分，批量复用才选日期范围；记录页已有独立记账本。见[本轮映射](deliverables/10-日期归属批量计划记账与用户映射.md)。

## 实现状态

当前 Android 实现单日计划、批量复用、实际计时、睡眠、饮食、记账、提醒和备份。“我的”改为顶部用户卡与设置列表；云端登录以昵称/密码为主，UID 用于同名账户区分。日计划导入支持本应用 JSON 与双模式 TXT 模板；记录页直接显示热量和收支卡片，首页与详情共用日期。Spring Boot 后端、MySQL 迁移与计划/记账/饮食统一同步已实现；离线队列、幂等、版本冲突和关联快照已接入。当前 Android 与云端后端为 `0.3.2`，已生成连接 `https://43.142.121.249` 的 APK。2026-10-22 用户通过 SSH 完成服务器升级，随后电脑公网验证 HTTPS 证书正常、健康接口返回 `ok`、未登录账户接口返回 `401`。手机实际登录与同步仍待覆盖安装后验收。浏览器原型继续只使用示例数据。

用户反馈手机简单测试未发现明显问题；仍需继续完成手机流量同步、异常场景及异机备份验收。后台用户查询命令和公共食物审核方案已整理，管理网页与公共库功能尚未实现。多段计时整体纠错、重叠拆分、饮水、周期、自定义记录及 AI 继续属于后续范围。

详细范围和验证记录见 [交付总览](deliverables/README.md)。
